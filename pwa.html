만드는 것

어떤 앱·웹을 만드나요

PlusHome Agency는 일상과 업무에서 "이런 게 있으면 좋겠다" 싶은 것을 직접 만들어 씁니다.
대부분 설치되는 웹앱(PWA)으로 시작하고, 필요하면 업무용 웹 도구나 데스크톱 유틸리티로 만듭니다.

만드는 것의 종류

PWA

설치되는 웹앱

홈 화면에 설치해 앱처럼 쓰는 웹앱입니다. 예: PlusHome, BlackCore

Web

업무용 웹 도구

관리자 화면, 게시판, 데이터 입력·조회처럼 반복 업무를 줄이는 도구입니다.

Desktop

데스크톱 유틸리티

작업 환경을 편하게 만드는 작은 프로그램입니다. 예: SubDock (macOS)

Site

소개 사이트

서비스나 결과물을 정리해 보여주는 사이트입니다. 지금 보고 계신 이 사이트도 그중 하나입니다.

왜 PWA로 시작하나요?

PWA(Progressive Web App)는 브라우저로 만들어지지만, 홈 화면에 설치되고 앱처럼 켜지는 웹사이트입니다.
앱스토어 심사 없이, 하나의 코드로 안드로이드·아이폰·PC에서 모두 작동합니다.

기술적으로는 여전히 웹사이트라서 만들고 고치는 속도가 빠릅니다.
직접 쓰면서 불편한 점을 바로 고쳐 반영할 수 있어서, 대부분의 결과물을 이 방식으로 먼저 만듭니다.

만드는 원칙

직접 쓰는 것부터 만듭니다. 실제로 매일 쓰는 도구라야 불편한 점이 보이고, 계속 고쳐집니다.
작게 시작해 계속 업데이트합니다. 처음부터 완벽하게 만들기보다, 필요한 기능부터 내놓고 다듬습니다.
운영까지 책임집니다. 배포, 도메인, 데이터 관리까지 직접 운영하면서 쌓은 경험을 다음 결과물에 반영합니다.
